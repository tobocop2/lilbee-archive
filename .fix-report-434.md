# PR #434 review fix report

## Main fix: embed ingest fan-out (pipeline.py)

Old: `embed_slots = cfg.embed_replicas if cfg.embed_replicas > 1 else 0` -- with the new `0`=auto default this always yielded 0 and fell back to `cpu_quota()`, starving every GPU beyond the first.

New: `embed_slots = resolve_replica_count(WorkerRole.EMBED, gpu_device_count())` -- mirrors the vision branch exactly. `max(cpu_quota(), embed_slots)` ensures a many-core CPU-only box still fans out by core count.

New test `test_auto_embed_replicas_fans_out_to_gpu_count`: mocks `embed_replicas=0` and `gpu_device_count()=4`, asserts result >= 4.
